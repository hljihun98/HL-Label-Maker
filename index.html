일반 A4에 시험 인쇄해 라벨지에 겹쳐 보고 맞추세요. A4 모드에서 정합 테스트 인쇄를 누르면 격자 전체가 인쇄됩니다.

③ QR · 바코드

Apps Script 원본 URL은 너무 길어 QR 셀이 작아집니다. 짧은 리다이렉트 주소를 쓰세요.

셀(모듈) 0.37mm 이상을 양호로 봅니다 — 현재 프린터·유포지 조합에서 0.38mm 인식을 확인했습니다. 용지나 프린터를 바꾸면 다시 확인하세요.

기본값은 품번입니다 — QR과 1D 바코드가 모두 품번을 담아, 스캐너·폰 어느 쪽으로 읽어도 같은 품번이 나옵니다. 박스 ID로 바꾸면 1D 바코드에는 품번이 들어가지 않습니다(QR에는 그대로 남습니다).

④ 표시 · 글자 · 괘선

끄면 로케이션이 빈 자재 라벨(이미지)에서 LOC 칸을 아예 인쇄하지 않습니다. 나중에 손으로 적어 넣는 운용이면 켜세요. 기존 자재 라벨은 이 설정과 무관하게 항상 수기칸을 남깁니다.

품명이 길어 잘리면 글자 배율을 0.9로. 열전사 프린터에서 괘선이 뭉치면 0.25mm로.

⑤ 박스 ID 채번

박스 ID = 접두 + YYMMDD + 일련번호. 라벨 1장 = 실물 박스 1개.
순번은 입고일별로 이 브라우저에 저장되므로 창을 닫고 다시 열어도 이어집니다. 라벨 훼손으로 재인쇄할 때만 시작 번호를 원래 값으로 되돌리세요 — 박스 ID는 반드시 원래 번호를 유지합니다.

정합값이 확정되면 assets/js/core.js 의 const CAL = {…} 숫자를 고쳐 저장해두면 다음에 열 때도 그대로 적용됩니다.
